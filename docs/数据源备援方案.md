## 3. 稳定性机制（已实现）

- **自动重连**：断线指数退避 1s→2s→4s…上限 30s（feed.mjs `retry()`）
- **心跳 + watchdog**：认证 12 秒超时主动断开重连
- **过期标记**：行情 60 秒未更新在 API 层标 stale（供监控与备援切换使用）；前台呈现与原站一致——始终显示最后值，不置灰、无角标、无顶部过期警告（2026-10-22 调整）
- **状态暴露**：`GET /api/status` 返回 `sourceStatus`
- **实测**：2026-10-22 09:13 起连续运行 5 小时以上零断线

## 4. 备援切换层（待实施）

设计原则：**备援只顶替数据，不改公式/基差配置**。

1. **检测**：某品种融通金字段 stale 超过 60 秒，且对应新浪备援有有效值 → 备援顶替
2. **状态**：`/api/status` 增加 `fallback` 字段（列出备援中的品种），后台显示"备援中"徽标
3. **恢复**：融通金该品种恢复推送且时间戳更新后自动切回
4. **拉取参数**：Referer 必须 `https://finance.sina.com.cn`；超时 8s；轮询 15s；GBK 编码用 latin1 解码（数字段为 ASCII）
