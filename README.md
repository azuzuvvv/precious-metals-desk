# 龙城金艺独立报价盘

本项目使用自己的服务端、配置数据库和管理员账号。不会修改或连接旧报价后台的写入接口。

## 本地启动

需要 Node.js 24（使用其内置 SQLite）。在项目目录运行：

```powershell
npm ci
npm start
```

打开 http://127.0.0.1:3188/ 查看报价，http://127.0.0.1:3188/admin 管理新盘。

首次启动自动在 `data/setup-token.txt` 生成一次性初始化令牌。打开该文件，将令牌填入新后台并设置不少于12个字符的密码。初始化后令牌文件自动移除。无默认密码，不复用旧系统密码。会话有效期8小时；重启需要重新登录。

## 报价规则

- 黄金默认直接使用源行情。实际销售基差由后台公式配置，例如销售公式设置为 `【#黄金#销售价】+3.5`；四舍五入保留两位。
- 每个品种独立设置回购、销售、最高、最低公式、精度、舍入、排序与可见性。
- 公式允许十进制数字、`+ - * / ( )` 和价格引用，例如 `【#黄金#销售价】+3.5`，或 `(【#黄金#销售价】*2+【#黄金#回购价】)/3`。
- 空公式表示不显示报价。计算不使用 JavaScript eval；无效公式不允许保存。
- 后台预览不保存，点击保存才影响新盘。版本冲突需重新加载后编辑，避免覆盖他人改动。
- 历史记录保留更改时间和版本，数据库中保存完整前后配置。前台“自选”只影响该浏览器。

## 行情与缺失数据

服务端根据融通金网页公开协议建立单个 WebSocket 连接，解码 Protobuf，维持心跳与退避重连。握手参数仅在服务端启动时从公开脚本读取并保存在内存，不写入前端或磁盘。它不是官方承诺稳定的商业 API；源站脚本或协议变化可能需要维护。

连接状态、源站交易状态、门店营业时段分别处理。超过60秒没有更新的依赖价格标为过期；心跳不会刷新报价时间。停盘品种也可能被标记为旧价，这是预期行为。营业时段按北京时间计算，跨天时段需在相邻日期分别填写。

在已验证的融通金品种目录里，尚未找到港金、美元指数、公斤条及部分原系统专有数据。因此保留原行和原公式，但缺失项显示 `--` 并给出原因，不用其他来源冒充。原盘“铑金”的销售公式实际含黄金组合减公斤条价格，照原式保留，需要公斤条数据才能计算。这些数据覆盖差异意味着当前不能声称所有品种数值都与旧盘完全一致。

## 数据与备份

运行数据在 `data/quotes.sqlite`（含密码哈希、配置和完整版本历史），不应提交到版本库。不要在服务运行时仅复制主数据库而忽略 WAL。使用在线一致性备份：

```powershell
node scripts/backup.mjs
```

备份存入 `data/backups/`，请另外复制到安全位置。后台“导出配置”只备份当前配置，不包含账号。恢复完整数据库时先停止程序，将备份恢复为 `data/quotes.sqlite`，在专门备份原运行目录后处理原 WAL/SHM 文件，再重启；不要混用旧数据库附属文件。

## 手机访问和部署

默认只监听本机。局域网试用可显式设置本机实际内网地址：

```powershell
$env:HOST='0.0.0.0'
$env:PUBLIC_ORIGIN='http://192.168.1.100:3188'
npm start
```

将示例IP替换成电脑内网IP，手机连接同一网络，防火墙只向需要的私有网络开放端口。设定 PUBLIC_ORIGIN 后，用该地址访问（主机名检查会拒绝其他地址）。公网部署必须使用 HTTPS 和对应 PUBLIC_ORIGIN，并为出站融通金 WebSocket 8443 端口放行；建议固定 Node 版本并配置进程守护和备份。当前交付是本地验收版本，未部署公网、未替换旧站。

## 验证

```powershell
npm test
npm run probe
```

测试覆盖十进制计算、公式攻击输入、缺失行情、报价过期、独立后台权限、CSRF、版本冲突、持久化与审计。probe 只读取一组实时黄金价格后退出。实时价格随时间变化，不应拿不同时间截图直接判断价差错误。

## 项目结构

- `src/feed.mjs` / `quote.proto`：独立源行情协议。
- `src/formula.mjs` / `config.mjs`：计算、配置校验与输出。
- `src/store.mjs` / `server.mjs`：SQLite、权限、只读报价和后台API。
- `src/defaults.json`：读取原公开配置形成的初始值。
- `public/`：报价页和独立后台。
- `test/`：自动化验证。

公开品牌资源用于本次用户要求的自家报价盘复刻；不复用原软件提供商跟踪脚本、管理员链接或凭据。
